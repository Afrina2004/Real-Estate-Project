# 🏡 Dream House

A modern, responsive real estate web application built with **React**, **Vite**, **TailwindCSS**, and **Firebase**. This project showcases property listings, user authentication, filtering, and booking/contact functionality.

---

## 🚀 Features

- 🔥 Fast development with **Vite**
- 🎨 Styled with **Tailwind CSS** and **DaisyUI**
- 📱 Responsive and mobile-first design
- 🔐 User Authentication (Firebase)
- 💾 Persistent storage with **localForage**
- 🗺️ Dynamic Routing with **React Router**
- 🧭 SEO support using **React Helmet**
- 🛠️ Toast notifications with **React Toastify**
- 🎠 Carousel integration via **Swiper**
- 🔍 Smart search & filtering with **match-sorter**
